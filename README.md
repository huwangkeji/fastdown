## 📖 项目简介

`install.php` 是一个**单文件**的 PHP 网页安装器，用于把远程的压缩包程序（`.zip`）分发并安装到你的服务器或虚拟主机站点根目录。

它适合：

- 🧑‍💻 个人开发者 / 小团队分发自研 Web 程序
- 🏢 面向无人值守场景的「傻瓜式」安装体验
- 🔌 需要自定义标题、下载地址、底部署名的品牌化安装页

全程可视化引导，无需命令行，普通用户也能在浏览器里完成安装。

---

## ✨ 功能特性

- ✅ **单文件即装即用**：只需上传一个 `install.php`，无其他依赖组件。
- 🔍 **智能环境检测**：自动检测 PHP 版本及 8 项必需扩展，绿色对勾逐一展示。
- ⬇️ **实时下载监测**：`curl` 流式下载 + 前端轮询，秒级显示下载进度（百分比 / MB）。
- 📦 **一键自动解压**：自动解压到临时目录、防路径穿越、规避覆盖自身，再合并到站点根目录。
- 🧹 **完成后自动清理**：解压完成自动删除 `shop.zip` 与临时文件，清爽收尾。
- ⚡ **强制安装模式**：服务器缺失扩展时可选择「强制安装」跳过继续。
- 🎨 **企业深蓝主题**：传达信任、专业与可靠性的深藏青视觉风格。
- ⚙️ **配置可自定义**：通过 `installer_config.json` 手动修改标题、下载地址、底部文字。
- 🗑️ **安全收尾**：安装完毕后可一键删除安装器本身并跳转站点首页。

## 📁 目录 / 文件说明

| 文件 | 说明 |
|------|------|
| `install.php` | 安装器主程序（唯一需要部署的文件） |
| `README.md` | 本说明文档 |
| `installer_config.json` | *(可选)* 自定义配置：标题 / 下载地址 / 底部文字 |
| `shop.zip` | *(运行时临时生成)* 下载到本地的安装包 |
| `.installed.lock` | *(运行时自动生成)* 安装完成标记 |
| `.download.progress` | *(运行时自动生成)* 下载进度临时文件 |

> 除 `install.php` 外，其余文件在**首次使用后**由程序自动生成；`installer_config.json` 仅当你需要自定义时才手动创建。

## 🖥️ 运行环境要求

- **PHP ≥ 7.4**
- **必需扩展**（缺失会默认阻止安装，可强制跳过）：

| 扩展 | 用途 |
|------|------|
| `PDO` | PHP 数据库访问接口 |
| `pdo_mysql` | 连接 MySQL / MariaDB |
| `mbstring` | 多字节字符串处理（中文等） |
| `gd` | 验证码、图片缩略图等功能 |
| `curl` | HTTP 请求及外部服务对接 |
| `openssl` | 加密、安全通信 |
| `json` | JSON 数据处理 |
| `zip` | 压缩包解压功能 |

- **操作系统**：Windows / Linux 均兼容（下载进程已做双平台适配）。
- **Web 服务器**：Apache / Nginx 均可，站点根目录需有**写入权限**。

## 🚀 快速开始（三步安装）

### 第 0 步：准备

1. 上传 `install.php` 到你的站点根目录（如 `www/shop/install.php`）。
2. 确保目标压缩包地址可从外网访问。

### 第 1 步：环境检测

浏览器访问：

```
http://你的域名/install.php
```

点击 **「🔍 检测环境」**，逐项展示 PHP 版本与扩展检测结果：

- ✅ 全部绿色 → 点击「⬇️ 开始下载」继续；
- ⚠️ 有红叉 → 可修复服务器后重测，或点击「⚡ 强制安装」跳过继续。

### 第 2 步：下载程序

点击 **「⬇️ 开始下载」**，页面实时显示下载进度（进度条百分比 + 已下载 MB / 总大小）。

### 第 3 步：一键安装

下载达到 100% 后点击 **「📦 一键安装」**，程序自动解压并合并到站点根目录。

完成后：

- 页面提示 **「下载完成，共解压 N 个文件」**；
- 点击 **「🗑️ 删除安装器并访问网站」** 自动删除 `install.php` 并跳转到站点首页。

> 💡 无需重复访问安装器时，建议安装完成后删除安装器本身，避免被人重复触发安装。

## ⚙️ 自定义配置

安装器默认读取以下默认值：

| 配置项 | 默认值 |
|--------|--------|
| `title`（标题） | `程序在线安装器` |
| `url`（下载地址） | `http://139.129.23.133:81/shop.zip` |
| `footer`（底部文字） | `沧州虎王科技 · 氢CMS 快捷安装器` |

如需自定义，在站点根目录**手动创建** `installer_config.json`：

```json
{
    "title": "我的品牌安装器",
    "url": "http://example.com/dist/shop.zip",
    "footer": "沧州虎王科技有限公司"
}
```

保存后刷新安装页即可生效；文件不存在时自动回退到默认配置。

> 🔒 **安全提示**：`url` 仅接受 `http(s)` 开头的合法 URL；`title` / `footer` 会被过滤标签以防止 HTML/脚本注入。

## 💡 常见问题（FAQ）

**Q：报错「未加载」的扩展怎么办？**
部分扩展需要在 PHP 配置文件（`php.ini`）中开启，如 `pdo_mysql`、`gd`、`openssl`。开启后重启 Web 服务再刷新检测即可。若确实无法开启，可使用「强制安装」。

**Q：下载一直停在 0%？**
请确认：

- 下载地址可被当前服务器网络访问（可用 `curl -I` 在服务器测试）；
- 服务器是否放行了目标端口；
- 部分虚拟主机 `allow_url_fopen` / `exec` 受限时无法分离后台进程，程序会自动降级为同步下载。

**Q：解压提示「安装包打开失败」？**
说明下载的 zip 不完整或已损坏，可删除 `shop.zip` 后重新下载。

**Q：安装完成后可以再次安装吗？**
可以。重新上传 `install.php` 并按流程操作即可（程序会覆盖已存在文件）。

**Q：安装器会被覆盖吗？**
不会。解压过程中程序会主动跳过 `install.php` 与 `.installed.lock`，避免覆盖正在运行的自身。

## 🛡️ 安全说明

- **路径穿越防护**：解压时过滤 `..` 目录穿越，阻止恶意压缩包越权写文件。
- **自身保护**：解压合并时自动跳过 `install.php` 与锁文件。
- **配置净化**：配置项过滤 HTML/脚本标签，`url` 仅限 `http(s)`。
- ⚠️ **建议**：安装器本身**不包含访问鉴权**。生产环境若长期保留，建议安装完成后删除，或在 Web 层限制访问，避免被他人触发安装。
